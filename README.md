# ecom-fe

> **Lollipop Sleek** — Aesthetic Lavender Luxury Boutique & Parisian E-Commerce Storefront.

Built with **Next.js 16 (Turbopack)**, **React 19**, and a **Calotes-inspired** `localStorage` e-commerce engine (no external database required).

---

## ✨ Features

- **🌸 High-Taste Aesthetic Design**: Soft lavender pastel palette, glassmorphism headers, arch frames, and custom typography (`Playfair Display` & `Alex Brush`).
- **🛍️ Complete E-Commerce Store Engine**:
  - Add to bag / remove / real-time quantity adjustments
  - Free Worldwide Shipping meter ($75 progress threshold)
  - Promo discount codes (`SLEEK15` for 15% off, `WELCOME10`, `FREESHIP`)
  - Order checkout flow with order ID & confirmation modal
  - Wishlist drawer with count badges & one-click move to bag
  - Live instant catalog search modal (searches title, category, description)
  - Quick view modal with color variant selectors
- **📱 100% Fully Responsive**: Pixel-perfect layout across desktop, tablet, and mobile with slide-over drawers.
- **⚡ Next.js App Router**: Optimized with Turbopack for sub-second hot reloads.
- **💾 Local Storage Persistence**: State persists cleanly across page reloads without database dependencies.

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore the boutique.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **UI & State**: React 19, Context API, LocalStorage
- **Icons**: Lucide React & Custom SVG Icons
- **Fonts**: Google Fonts (`Alex Brush`, `Playfair Display`, `Plus Jakarta Sans`)
- **Styling**: Vanilla CSS Design System with CSS variables

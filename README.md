# Faeries Junk 🧚‍♀️ (`@faeriesjunk.store`)

> **Curated & Handpicked Vintage Rags by [@aryaamishraa](https://www.instagram.com/faeriesjunk.store/)**

An intimate, high-taste e-commerce boutique for 1-of-1 archival fairycore tops, 90s lace corsets, ethereal pleated slip dresses, and vintage bags. Shipping across India 🇮🇳.

Built with **Next.js 16 (App Router + Turbopack)**, **React 19**, and a **localStorage** client store engine (no DB required).

---

## 📌 Boutique Policies

- **No COD ❌**: Strictly prepaid orders via UPI / Cards / NetBanking.
- **No Returns or Cancellations**: All drops are delicate, pre-loved 1-of-1 vintage garments with precise measurements.
- **Shipping Across 🇮🇳**: Dispatched via express courier within 48 hours. Free delivery on orders over ₹1,999!

---

## ✨ Features

- **🌸 Authentic 1-of-1 Vintage Drops**: Butterfly halter camis, French lace corsets, fairycore slip dresses, distressed suede bags, and raw quartz crystal chokers.
- **🛍️ Complete E-Commerce Store Engine**:
  - Add to bag / remove / real-time quantity adjustments
  - Free Courier Delivery progress bar across India (₹1,999 threshold)
  - Promo discount codes (`FAEJUNK10` for 10% off, `FAEVIP15`, `FAEFREESHIP`)
  - Prepaid checkout flow with Claim ID & confirmation modal
  - Wishlist drawer with count badges & one-click move to bag
  - Live instant catalog search modal (searches title, category, description)
  - Quick view modal with condition grades & sizing details
- **📱 100% Fully Responsive**: Pixel-perfect layout across mobile, tablet, and desktop with slide-over drawers.
- **⚡ Next.js App Router**: Optimized with Turbopack for sub-second hot reloads.
- **💾 Local Storage Persistence**: State persists cleanly across page reloads without database dependencies.

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore the boutique.
